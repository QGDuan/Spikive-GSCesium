# Spikive GS Inspector（Apple Silicon Mac）

本包适用于 M1/M2/M3/M4/M5 等 Apple Silicon Mac，已包含编译完成的前端和服务端，不包含示例模型或历史业务数据。

1. 先阅读 [USER_GUIDE.md](USER_GUIDE.md)。
2. 打开“终端”，进入本目录并执行 `./install.sh`。
3. 安装完成后执行 `./start.sh`。
4. 使用 Chrome 打开 `http://localhost:3000`。

运行数据保存在本目录的 `var/`，升级和迁移前请完整备份。系统生成的航线仅为候选结果，不能替代现场和飞行安全审核。
