# Spikive GS Inspector 客户测试包

本包已经包含编译完成的前端和服务端，不包含任何示例模型或历史业务数据。

1. 先阅读 [USER_GUIDE.md](USER_GUIDE.md)，正文为中文。
2. macOS/Linux 执行 `./install.sh`，Windows 执行 `install.cmd`。
3. 安装完成后执行 `./start.sh` 或 `start.cmd`。
4. 浏览器打开 `http://localhost:3000`。

运行数据保存在本目录的 `var/`，升级和迁移前请完整备份。系统生成的航线仅为候选结果，不能替代现场和飞行安全审核。
