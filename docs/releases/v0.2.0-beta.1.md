# v0.2.0-beta.1 — PlayCanvas 主线候选

## 变更

- 生产入口迁移为 PlayCanvas 2.21.4 单 Renderer：WebGPU/GPU Sort 优先，WebGL2/CPU Sort 回退。
- 新上传和视觉重建只生成 PlayCanvas 视觉 LOD，不再生成 Cesium 或 AHoLo 视觉 LOD。当前 V4 的全部密度层均以 float PLY 发布。
- 标签拾取继续由 PlayCanvas 相机射线调用同一后端 SVO；法向、碰撞、膨胀扫掠和规划算法不变。
- 保留可点击标签、高亮弹窗、红色 inspection 点、蓝色 transit 点、绿色有效路线和橙色安全前缀；`hj_` 名称不显示文字。
- 增加受控预算/LOD 调参和右上角 PlayCanvas 性能监控，不根据 FPS 自动降画质。
- 增加 `/renderer-lab`，但一次只运行 PlayCanvas WebGPU、PlayCanvas WebGL2 或冻结 AHoLo 中的一种。
- 语义能力只写入长期路线，没有新增语义代码、表、接口或产物。

## 数据升级

- 历史只有 AHoLo/Cesium 视觉的数据需执行一次“构建 PlayCanvas 视觉”。
- 视觉重建复用并校验碰撞 SVO，不修改标签、任务和航点。
- AHoLo 字段、GET 路由和产物只读保留一个发布周期；不会被升级自动删除。
- 活动视觉通过版本 manifest 原子切换，旧版保留七天并支持显式回滚。

## 上线门禁

本版本是候选而非默认客户稳定版。必须完成代表性 14.22M 数据的画质、30 FPS、白边、射线/规划一致性、WebGPU/WebGL2 和 50/20 轮生命周期验收后，才能激活为客户 Main；失败则使用冻结 AHoLo 版本定位。
