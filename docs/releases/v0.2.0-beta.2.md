# v0.2.0-beta.2：官方 PlayCanvas 基线重置

## 变更

- 固定未修改的 `@playcanvas/splat-transform@3.3.0` 与 `playcanvas@2.21.4`。
- 视觉构建改为官方 Streamed SOG 示例：100%、50%、25%、10%，其余参数全部使用上游默认值。
- 删除转换器补丁、全 PLY 视觉格式、自定义 Chunk Loader、运行时预算/LOD 调参和 AHoLo 实验入口。
- 前端直接使用 PlayCanvas 原生 `gsplat` Asset/Component；性能面板仅做只读观测。
- 保留从全量源 PLY 独立生成 SVO 的业务分支，以及标签、法向、膨胀碰撞和航迹规划对 SVO 的使用。
- 视觉仍采用版本化构建、校验和原子发布；失败继续服务旧版，不自动切换参数。

## 升级说明

历史视觉产物不会在安装依赖时自动删除。对现有数据集执行一次“重建 PlayCanvas 视觉”即可生成官方基线；碰撞、标签与任务不受视觉重建影响。若历史碰撞曾对源数据使用视觉专属坐标变换，应执行一次完整数据重建，确保 SOG 与 SVO 同源同坐标。
