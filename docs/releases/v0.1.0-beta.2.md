# Spikive GS Inspector v0.1.0-beta.2

本版本取代 beta.1 的通用压缩包，按操作系统提供两个独立客户测试包：

- `Spikive-GS-Inspector-v0.1.0-beta.2-macos-apple-silicon.zip`
- `Spikive-GS-Inspector-v0.1.0-beta.2-windows-x64.zip`

两个包均为在线安装包：包含已构建的应用，不包含 `node_modules`，首次执行安装脚本时需要联网。包中不包含源 PLY、SQLite、标签、航线或任何历史业务数据。

## 平台范围

- 提供 Apple Silicon Mac 与 Windows x64 两个独立客户测试包。
- 根据交付安排，本版本未在独立 Mac/Windows 客户机器上执行安装、PLY 转换和大场景性能验收；首次测试请使用非生产数据并保留完整日志。
- Intel Mac 和 Windows ARM64 不属于本版本完整支持目标。

## 安全与数据

- 客户数据继续保存在安装目录的 `var/`，升级前必须完整备份。
- 安装包构建会拒绝 PLY、SQLite、环境变量文件和 `node_modules`。
- 航线是基于当前碰撞模型生成的候选结果，实际飞行前必须人工复核。
