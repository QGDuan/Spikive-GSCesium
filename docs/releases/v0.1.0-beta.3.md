# Spikive GS Inspector v0.1.0-beta.3

本版本将 AHoLo 从候选 Renderer 提升为 `main` 唯一 Renderer，并冻结旧 Cesium 实现。

## 主要变化

- 前端只创建 AHoLo Viewer；移除 Cesium 依赖、页面入口、Shader 补丁和 3D Tiles 转换链。
- 上传处理固定生成 AHoLo 无损 PLY Chunk、高精度 ESZ v2 与独立碰撞 SVO。
- 标签拾取、表面法向、体素碰撞和航迹规划继续由统一局部 Z-up 数据真源驱动。
- AHoLo 中保留可点击标签、选中高亮、红色巡检观察点、蓝色途经点、绿色有效线路和橙色安全前缀。
- `minLevel`、Gaussian 预算和调度参数开放为浏览器会话级调参，不影响碰撞与任务。
- 新主线不自动删除历史 Cesium 产物；冻结版本保存于 `archive/cesium-final` / `v0.1.0-cesium-final`。

## 升级提示

- 升级前停止服务并完整备份 `var/`。
- 只有已有 AHoLo revision 且坐标审计为 Z-up 的数据可直接显示。
- 历史仅有 3D Tiles 的数据需要在界面执行“构建 AHoLo 视觉”；该操作复用并校验碰撞，不修改标签和任务。
- Intel Mac 不再有 Cesium 回退，因此不属于本版本支持平台。
