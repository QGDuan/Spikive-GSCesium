# Spikive GS Inspector v0.1.0-beta.1

首个面向客户测试的 Beta 版本。

## 主要能力

- GraphDECO PLY 断点续传、受管源数据和处理状态。
- Cesium Gaussian 3D Tiles 高清自适应 LOD，以及独立 AHoLo Chunk LOD 本地巡检视图。
- 碰撞 SVO 负责 GS 表面拾取、法向解析、标签吸附与无人机机体膨胀碰撞检查。
- 巡检标签与 GS 数据集绑定，支持点击、高亮和详情查看；被任务引用的标签禁止直接删除。
- 根据巡检标签、起点和飞行参数生成候选航线，红色为观测点、蓝色为途经点、绿色为完整有效候选航线、橙色为不可执行的安全前缀预览。
- 视觉产物与碰撞产物独立版本管理；视觉重建不改变标签或航迹计算真值。

## 客户测试包

下载 `Spikive-GS-Inspector-v0.1.0-beta.1-customer.zip`，校验 SHA-256 后解压。按照包内 `USER_GUIDE.md` 完成环境准备、安装、启动和业务测试。

测试包不包含开发者现有模型、SQLite、标签、航迹或其他业务数据。首次启动会创建自己的 `var/` 数据目录。

## 已知边界

- 首次安装需要联网下载生产运行依赖。
- 大规模 PLY 的视觉切片和碰撞处理需要足够的 GPU、内存、磁盘与处理时间。
- AHoLo 属于本地大场景候选 Renderer，可随时回滚 Cesium；两套 Renderer 不会同时挂载。
- Cesium Gaussian Splatting 仍属于实验能力，实际画质和资源稳定性需要使用代表性场景验收。
- 系统输出是通过当前模型检查的候选航线，不是自主飞行许可；真实飞行前必须完成现场、机型、法规和安全复核。
