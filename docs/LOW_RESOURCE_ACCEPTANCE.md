# 低资源构建测试记录

日期：2026-09-20。范围：`test` 分支低资源切片、分区 SVO、调试附件、分页规划与数据恢复。`main` 保留优化前稳定版，不自动合并本次实现。

## 结论与适用范围

本机完整生成约 1422 万 Gaussian 的五级 Streamed SOG 和分区 SVO。未减少 LOD0 数量，未自动改变体素尺寸或透明度阈值；小场景逐体素对照、自动回归及打包后端测试通过。

本次机器是 **Apple M5 / 16GiB 统一内存 / macOS arm64 / Node v24.18.0**。不能把统一内存 GPU 资源估算等同于 Windows 独显显存。**Windows 16GB RAM / 4GB VRAM、真实设备挂起及浏览器人工检查尚待验证**；本记录不是对所有低配设备成功率的保证，也不是无人机实飞安全认证。

固定版本：前端 `playcanvas@2.21.4`；未修改的官方转换器 `@playcanvas/splat-transform@3.4.2`。未增加渲染器、Shader 或规划算法。

资源测量为每秒采样当前验收进程及子进程 RSS，加官方 `--memory` 输出。采样可能遗漏极短峰值；GPU 数值不是整机显存监控。结果保留同一次验收目录各阶段和续算尝试中的最大值。脚本在 Windows 未取得 RSS 时不会输出“资源门槛通过”。

SOG 使用官方默认编码，不能由字节大小推断逐属性无损；这里的完整性结论是 LOD0 数量完整，不是新增画质验收。没有修改源颜色、尺度或缺失的 SH。

- 参数：0.5m / 0.1。

- 官方整场裁剪边界与分区 `queryBounds` 相同；未知空间没有因源离群点包围盒而扩大。
- 球体膨胀查询与跨区扫掠结果一致。
- 调试 GLB 成功生成 7,144 字节，重算 SVO 二进制和网格边界与原碰撞产物一致。

`npm test`：50 项全部通过。覆盖原有标签 CRUD、唯一起点、引用删除约束、坐标、法向和规划规则，以及新增：

API 故障用受控的假转换程序注入，验证的是状态和恢复闭环，不是 Windows 驱动故障复现。常规测试不重新切片业务数据。

其他检查：TypeScript 和 Vite 生产构建通过；`npm run deploy:web` 通过；打包后端运行同一构建 API 回归通过；生产依赖 `npm audit --omit=dev` 为零漏洞；Skill 快速校验通过。构建保留现有大包尺寸及浏览器 worker 外部化提示，无编译错误。

## 尚未通过实机验证的门槛

1. Windows 16GB / 4GB 独显及客户 RTX A2000 的整场首跑、驱动挂起和恢复。
2. 真实内存不足、真实磁盘耗尽、真实设备丢失的硬件级复现；当前仅有状态故障注入。
3. 浏览器新增控件布局、构建期间镜头保存/恢复，以及长时间场景切换资源回收；当前没有可用的浏览器控制连接，未进行人工视觉确认。
4. 用户真实标签集合在旧碰撞与新碰撞下的任务逐项比对；当前使用合成有效任务对照，未重写业务数据库。
5. 极端巨大/高重叠 Gaussian。官方 CLI 没有输出 AABB 裁剪，最小核心仍可能因跨区贡献集或输出网格过大失败，系统应明确停止，不能自动降低精度。

以上门槛保持可追踪，`test` 可用于下一轮客户机器验证；不能据此自动替换稳定 `main`。使用方法、接口及限制见 [低资源构建说明](LOW_RESOURCE_BUILD.md)。
