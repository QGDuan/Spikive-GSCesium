# AHoLo 渲染、Chunk LOD 与生命周期

## 1. 单 Renderer 契约

生产入口只挂载 `AholoScene`。AHoLo Viewer 同时绘制 Gaussian、巡检标签、选中高亮、航点和折线，确保各对象使用同一相机和投影。代码库拒绝 Cesium、Three、Luma WebGL 等第二渲染运行时，也不允许手写第二个 WebGL context。

依赖固定为：

- `@manycore/aholo-viewer@1.8.1`
- `@manycore/aholo-splat-transform@1.7.4`

升级任一版本都必须重新验证 Chunk 元数据、公共 API、坐标投影、拾取射线、资源销毁和代表性大场景。

## 2. 视觉产物

每个视觉 revision 同时包含：

- `esz/`：高精度 ESZ v2，生产默认格式；
- `ply-reference/`：无损 PLY Chunk，作为近景画质对照；
- `aholo-report.json`：源摘要、坐标、层级、字节和碰撞 revision；
- `lod-meta.json`：Chunk 树、包围盒、层级切片和文件列表。

两种格式必须具有完全相同的 LOD0 点数、SH 阶数和 Chunk 拓扑。任一校验失败都不能激活 revision。源数据为 SH0 时系统只保留其颜色能力，不伪造高阶 SH。

## 3. 固定 Chunk LOD 策略

| 层级 | 数据比例 | Scale Boost | 常驻/合并 |
|---:|---:|---:|---|
| 0 | 100% | 1.00 | 否 |
| 1 | 50% | 1.00 | 否 |
| 2 | 25% | 1.00 | 否 |
| 3 | 5% | 1.01 | 是 |
| 4 | 1% | 1.02 | 是 |

单 Chunk 上限为 400,000 Gaussian。低密度常驻层先建立全场轮廓，靠近后由细层流式替换；LOD0 必须保留全部有效 Gaussian。构建采用无损分块后逐 Chunk 转换 ESZ，避免同时解码整个场景。

默认运行参数：6,000,000 Gaussian 预算、`minLevel=0`、`backgroundPenalty=0.5`、`hysteresisTicks=4`、并行调度 4、缓存任务 64、最短调度间隔 160 ms。界面允许在当前会话内调整：

- `minLevel`：限制最细可请求层；0 表示允许 LOD0；
- `maxBudget`：当前场景可见 Gaussian 预算；
- `backgroundPenalty` 与距离步长：影响前后景和距离评分；
- 调度并行数、任务缓存和最短调度间隔：控制请求/解码节奏。

这些设置不会持久化，也不改变视觉文件、SVO、标签或航线。系统不会以帧率为由静默覆盖用户设定。

## 4. 相机与坐标

AHoLo 使用渲染坐标 `render=(x,z,-y)`；所有持久数据使用局部 Z-up `local=(x,-z,y)`。标签点、法向、路线点和拾取射线必须使用同一组互逆函数，禁止在各功能中复制符号交换逻辑。

相机是唯一输入控制器。标签模式只把单击转换成射线，拖动仍由 Viewer 相机处理；通过点击移动阈值区分拾取和相机旋转。数据集聚焦从 LOD 根包围盒计算 target 与距离。

## 5. 标签、航点和线

- 标签对象使用固定屏幕尺寸，支持点击和选中高亮。
- 标签详情层绑定三维位置，逐帧投影到屏幕；离开视锥时隐藏。
- 标签关联的观察航点为红色，途经点为蓝色，Home 为中性色。
- 有效航线使用绿色 FatLine；无效任务只显示已复检的橙色安全前缀。
- `hj_<标签名>` 是任务数据中的关联语义，不在场景重复绘制文字。

渲染对象不参与规划。拾取、法向、碰撞净空、路径顺序与导出始终由后端产生。

## 6. 生命周期

React effect 以数据集 ID 和不可变视觉 revision 为资源边界。每次创建都有独立 AbortController；切换场景或卸载时：

1. 标记 runtime 已销毁，停止接受交互和叠加更新；
2. 中止 manifest、Chunk 和 SVO 请求；
3. 停止 LOD 调度与动画帧；
4. 释放 LodSplat、几何体、材质、Sprite 与线对象；
5. 移除 DOM 标签和事件监听；
6. 最后销毁 Viewer。

Chunk 加载取消使用专用错误类型；只抑制该精确取消错误，不吞掉真实加载失败。初始化失败、Chunk 404 或 context 丢失会显示错误并允许重试，不创建隐藏的替代 Renderer。

## 7. 验收门禁

- 固定 1080p、相同 FOV，在至少九个锚点和 30/100/500/1500 m 对比源 PLY、无损 Chunk 与 ESZ。
- 近景必须允许选择 LOD0；不能新增空洞、轮廓变软、尺度/旋转/Alpha/颜色失真。
- 同一点击的局部射线和 SVO 命中必须稳定；标签法向与航线结果不能随视觉格式或 LOD 参数变化。
- 600 万默认预算下不下载完整源 PLY，调度结束后内存稳定。
- 连续 50 轮拉近、拉远、旋转，以及 20 轮场景切换/清除，不得残留请求、帧循环、监听器或持续增长的 GPU 资源。
- `npm run check:rendering-architecture` 必须拒绝被重新引入的第二 Renderer 依赖或入口。
